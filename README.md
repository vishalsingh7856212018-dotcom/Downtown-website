# Down Town Cafe & Celebrations — Robertsganj

A classic, avant-garde website for **Down Town Cafe & Celebrations**, located in Basement RK Plaza, Robertsganj, Sonbhadra, Uttar Pradesh.

## 🌟 Highlights & Features
- **Botanical Velvet Noir & Burnished Gold Design**: Tailored luxury dark aesthetic with floating gold bokeh canvas particles.
- **Interactive Signature Menu**: Category filters with Dish Quick-View pop-up modal.
- **Milestone & Birthday Party Planner**: Instant calculator with custom theme inclusions and direct WhatsApp sharing.
- **Fast Table & Party Reservation**: Form validation with one-click WhatsApp pre-filled confirmation to the owners (`+91 9196363236`).
- **Cafe Sound Ambience**: Integrated Web Audio API binaural lounge chord player.
- **Full-Screen Photo Lightbox**: Visual gallery celebrating signature pizzas, sizzlers, mocktails, and moments.
- **Optimized for Netlify**: Zero build steps required; instant global edge deployment.
